# CIR4FUN Interactive Technology Architecture

Static, responsive HTML website for exploring the WP3, WP4 and WP5 architecture.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Deploy to Vercel
Use Framework Preset `Other`, Root Directory `./`, and Output Directory `.`. Leave Build Command and Install Command empty.

The interactive hit areas are positioned against the supplied 1536 × 966 architecture image and scale with the image to preserve alignment.
